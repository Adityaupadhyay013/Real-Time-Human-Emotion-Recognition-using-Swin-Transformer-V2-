# Real-Time-Human-Emotion-Recognition-using-Swin-Transformer-V2-
🚀 **Excited to share my latest Deep Learning project: Real-Time Human Emotion Recognition using Swin Transformer V2!**

Over the past few weeks, I've been exploring different deep learning architectures for facial emotion recognition. Instead of settling on the first model that worked, I experimented with multiple approaches to understand their strengths and limitations.

My journey looked something like this:
🔹 Built baseline CNN models
🔹 Experimented with ResNet50V2
🔹 Tried EfficientNetB2 for better feature extraction
🔹 Finally fine-tuned Swin Transformer V2, which delivered the best overall performance on my dataset.

### Project Highlights

✅ Developed a real-time human emotion recognition system using a fine-tuned Swin Transformer V2 model.
✅ Trained on the FER2013 dataset to classify seven emotions:

* Angry
* Disgust
* Fear
* Happy
* Sad
* Surprise
* Neutral

✅ Built a live webcam application using Streamlit, OpenCV, and WebRTC for real-time inference.
✅ Integrated OpenCV face detection to focus the model on facial regions, improving prediction confidence by reducing background noise.
✅ Achieved approximately **66% validation accuracy** with a **weighted F1-score of 0.65**.

### Tech Stack

🐍 Python | TensorFlow | Keras | Swin Transformer V2 | OpenCV | Streamlit | WebRTC

This project taught me a lot about:

* Transfer Learning
* Vision Transformers
* Real-time Computer Vision
* Model Fine-tuning
* Deployment with Streamlit
* Building end-to-end AI applications
